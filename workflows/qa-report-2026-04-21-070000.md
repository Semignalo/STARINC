## Remaining Issues (Belum Difix)

### Security
- **HIGH-1**: Admin guard frontend-only — acceptable, API tetap aman via `EnsureIsAdmin` middleware
- **HIGH-3**: `APP_DEBUG=true` — set `false` saat production deploy
- **HIGH-5**: No HTTP security headers — perlu `SecureHeaders` middleware di Laravel
- **MED-1**: CORS trusts multiple localhost origins — perlu diupdate saat deploy
- **MED-5**: Invoice endpoint perlu throttle rule
- **MED-6**: `appearance_settings_cache` menyimpan internal file URL di localStorage
- **LOW-5**: Latent XSS jika `product.description` disambungkan ke DB — perlu DOMPurify

### Mobile UX (Session 2 Fixes) ✅
- **P1**: Input font-size 16px — Login, ForgotPassword, Checkout (all 5 fields) ✅
- **P2**: Touch targets 44px — ProductTable edit/delete buttons, UserDetail copy button, Footer social icons ✅
- **P3**: `prefers-reduced-motion` guard in `index.css` ✅; `aria-label` on footer social icons ✅
- **Performance**: Hero videos `preload="metadata"`, below-fold videos `preload="none"` ✅; recharts lazy-loaded via React.lazy ✅
- **UX**: Admin Users currency format fixed (`Number().toLocaleString`) ✅

### UX (Perlu Effort Lebih)
- **CRITICAL (UX)**: Language mixing pervasive di seluruh app (English/Indonesian campur)
- **MAJOR**: Status label inconsistency (raw English di dashboard vs Indonesian pills di orders)
- **MAJOR**: Dead links (`#`) di footer, social media, Chat button, nav categories
- **MAJOR**: Page title `sdp-v2` di semua tab — perlu dynamic `<title>` per route
- **MAJOR**: Track Orders menampilkan "di perangkat ini" — seharusnya server-side per user
- **MINOR**: Tier icons di Admin Tiers render sebagai "br", "si", "go", "pl", "di"
- **MINOR**: Admin Products heading English ("Products / Manage your product inventory")
- **MINOR**: Profile tab labels mix English/Indonesian

### Performance (Perlu Effort Lebih)
- **MEDIUM**: 6 `<img>` tanpa `width`/`height` attrs — CLS risk
- **MEDIUM**: Tidak ada `React.memo` di list components
- **LOW**: First visible product images perlu `fetchpriority="high"` bukan `loading="lazy"`
